# Локальные состояния Git
Рабочая пакпка - это локальное хранилище, в котором хрянятся файлы разных расширений.

Индекс - это промежуточная область паямти, которая хранит список изменений, готовых для включения вследующий в следующий коммит.

Коммит - это снимок состояния проекта в определённый момент времени.

## Различие Git и Github
Git - это программа для отслеживания изменений в коде. 

Github - это сайт, где можно сохранять свои работы в интернете.

# Использование команды
git diff - это команда вывода разницы между коммитами, коммитом и рабочим каталогом и т.д.

git status - это команда вывода состояния рабочего каталога.

git diff --staged - это команда вывода разницы между состоянием файлов в индексе в последнем коммите.

## Ветки 
Ветка - это указатель на один из коммитов, представляющий собой независимую линию разработки.

При новом коммите указатель текущей ветки автоматически сдвигается вперёд, на только что созданный коммит.

Слияние (Merge) - это процесс объединения изменений из одной ветки в другую.
