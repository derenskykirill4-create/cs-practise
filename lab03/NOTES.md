## Различия git diff от git show и git log
git diff — сравнивает два разных состояния (между коммитами, индексами или рабочей директорией).

git log — исследует историю метаданных (кто, когда и зачем сделал коммиты).

git show — исследует один конкретный объект или коммит во всех деталях.

## Выполнение команд. Что выполнили git log -S и git blame
git log -S'string' -  Ищет по истории коммитов, в каких коммитах была удалена или восстановилась конкретная строка.

git blame - показывает всё содержимое файла, указывает для каждой строки дату изменения, автора и хэш коммита.

# Восстановление файлов
git restore <file> возвращает рабочую копию файла в состояние на момент состояния последнего коммита (~HEAD~), уничтожая все незакоммиченные правки. Если бы мы не сохранили их, они были бы безвозвратно утеряны.

git restore --source=<commit> <file>** — извлекает состояние файла из указанного коммита (например, из прошлого) и заменяет им текущую рабочую копию.
